# API 비용 보호와 테스트 연결

현재 목표는 유료 사용 확대 없이 무료 제공량 안에서 테스트하는 것이다. 이 문서는 앱의 차단 장치와 계정에서 필요한 설정을 구분한다. 실제 키나 계정 설정을 확인하지 않은 상태에서 비용 0원을 보장하지 않는다.

## 서버 요청 보호

루트 `.env`의 `GOOGLE_MAPS_REQUESTS_ENABLED`, `KAKAO_MAPS_REQUESTS_ENABLED`는 기본 `false`다. 키만 입력해도 외부 요청을 시작하지 않는다. 공급자별 무료 쿼터와 제한 설정을 확인한 후 필요한 공급자만 `true`로 바꾼다.

| 서버 요청 묶음 | 일간 제한 | 월간 제한 | 갱신 기준 |
| --- | ---: | ---: | --- |
| Google 장소 검색(리뷰 포함 추천 + 기존 기본 검색 합산) | 20 | 600 | America/Los_Angeles |
| Google 저장 장소 상세 조회 | 80 | 2,400 | America/Los_Angeles |
| Google 지역 검색 + 위치 역지오코딩 합산 | 80 | 2,400 | America/Los_Angeles |
| 카카오 Local 검색 + 주소 변환 합산 | 200 | 6,000 | Asia/Seoul |

한도는 사용자별이 아닌 같은 DB를 쓰는 앱 전체의 보수적인 개발 한도다. 가격표의 무료 제공량과 동일한 값이 아니다. Google 무료 사용량은 미국 태평양 시각의 월초에 갱신되며 결제 계정에 연결된 다른 프로젝트 사용량도 고려해야 한다. [공식 종량제 설명](https://developers.google.com/maps/billing-and-pricing/pay-as-you-go)

요청 흐름은 `기존 인증·입력 검증 → 외부 API Client → 사용 활성화 확인 → DB의 일간·월간 한도 동시 예약 → 공급자 요청`이다. `api-usage.service.ts`가 정책과 오류를 처리하고, `api-usage.repository.ts`가 단일 조건부 UPSERT로 예약한다. DB 작업은 Repository에 둔다. `ApiUsage`에는 서비스 이름·기간·시도 횟수만 저장하며 키·검색어·위치·공급자 콘텐츠는 저장하지 않는다.

- 동시에 들어온 요청도 한도까지만 예약된다. 서버 재시작이나 키 변경은 사용량을 초기화하지 않는다.
- 한도 초과 시 `429 MAP_USAGE_LIMIT_REACHED`; DB 확인 실패 시 `503 MAP_USAGE_UNAVAILABLE`; 활성화 전에는 `503 MAP_REQUESTS_DISABLED`를 반환한다. 모두 외부 호출 전에 중단한다.
- 실패·시간 초과도 예약을 반환하지 않으며 자동 재시도하지 않는다. 실제 청구 횟수보다 보수적으로 집계한다.
- 키 미설정 요청은 기존 연결 안내를 반환하고 횟수를 소비하지 않는다.
- Google 저장 장소의 상세 조회가 차단되면 기존의 위치 미확인 표시를 사용하고 해당 좌표를 지도·동선 계산에 쓰지 않는다.
- `api_usage` 삭제, DB 교체/오래된 백업 복원, 같은 키를 다른 앱/DB에서 사용하는 것은 이 한도를 우회한다. 그 경우 호출을 다시 끄고 공급자 사용량을 확인한다.

## 공급자 계정 설정이 필요한 이유

앱 카운터는 이 서버를 통과하는 요청만 센다. Google Cloud의 API별 할당량을 별도로 낮추고 API 키를 용도별로 제한한다. 예산 알림은 자동 결제 차단이 아니다. 한도 단위(요청/지도 로드), 다른 프로젝트의 사용량 및 현재 무료 제공량을 확인한다. 일간 한도가 없는 항목은 분당 한도만으로 월간 0원을 보장할 수 없다. [공식 비용 관리](https://developers.google.com/maps/billing-and-pricing/manage-costs)

카카오는 앱 정보의 **카카오맵 무료 쿼터** 배지를 확인하고, 무료 테스트에서는 유료 API 사용 설정/비즈월렛 연결을 진행하지 않는다. 무료 적용 앱이 아니면 새 앱을 반복 생성하지 말고 기존 무료 적용 앱을 사용한다. [카카오 이용 정책](https://developers.kakao.com/docs/ko/kakaomap/common)

웹 지도 SDK와 iOS 기본 지도는 서버의 API 카운터를 통과하지 않는다. 지도 표시용 키에는 지도 SDK만 허용한다. Google 웹 지도는 공급자 한도 설정 전까지 끄고, 카카오 웹 지도는 무료 적용 앱에서만 켠다. 무료 iOS 기본 지도 표시와 Places·Geocoding 호출은 서로 다른 서비스다.

## 검증

`npm test`는 외부 호출을 모의 처리하여 차단, 한도 초과, DB 장애, 요청 전 예약, 기간 계산을 검증한다. 실제 키를 쓰지 않는다.

마이그레이션 적용 후 로컬 DB에서 `ALLOW_LOCAL_DB_TESTS=true npm run test:integration:api-usage`를 실행하면 임시 카운터 하나로 동시 요청·재연결·기간 갱신을 검사하고 그 테스트 행만 삭제한다. 기존 운영 카운터나 여행 데이터를 변경하지 않는다.
