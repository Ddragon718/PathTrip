# 지역 방문자 추천

현재 위치로 해당 지역 방문을 확인한 회원이 추천 장소명·주소(선택)·추천 이유를 직접 작성한다. 거주자 인증이 아니므로 명칭은 **방문자 추천**, 배지는 **작성 당시 방문 인증**이다. 등록된 추천은 다른 회원이 지역과 분류별로 최신순 조회할 수 있다.

## 데이터 흐름과 인증 기준

1. 여행 지역 문자열을 서버가 Google Geocoding으로 도시/행정구역 place ID로 해석한다. API 키는 서버의 `GOOGLE_GEOCODING_API_KEY`이며 클라이언트에 노출하지 않는다.
2. 사용자가 인증 버튼을 누르고 위치 권한을 허용하면 클라이언트가 위치·정확도·측정 시각을 API에 전송한다. API는 Google 역지오코딩으로 위치가 속한 행정구역 ID들을 조회한다. 선택한 지역 ID와 정확히 일치해야 한다. 단순 사각 경계나 클라이언트의 인증 여부는 믿지 않는다.
3. 정확도 100m 이내, 측정 후 2분 이내(미래 시각 허용 15초)를 요구한다. 인증 유효기간은 서버 시각으로 24시간이다. 등록 시마다 DB 인증과 계정 활성 상태를 확인한다.
4. 정확한 위도·경도·정확도는 DB에 저장하지 않는다. 인증 테이블에는 사용자 ID·지역 place ID·인증/만료 시각만 저장한다. 글에는 직접 작성한 내용과 작성에 사용한 인증 시각을 저장한다.

Google 응답의 지역 이름은 표시 시에만 사용하며 영구 저장하지 않는다. 지역 조회와 인증을 위해 Google Geocoding API 사용 설정과 결제·서버 키 제한이 필요하다. 위치는 인증 요청 시 PathTrip 서버와 Google에 전달된다는 사실을 버튼 앞에 안내한다. 인증 만료 후에도 기존 글은 작성 당시 인증 배지로 유지한다.

## 권한 및 운영 범위

API는 Bearer 인증 필수. 목록은 지역·분류별 페이지당 최대 20개. 삭제는 작성자 또는 DB 역할이 ADMIN인 계정만 가능하고 soft delete한다. 탈퇴 회원의 글은 조회에서 제외한다. 요청 제한은 프로세스 내 IP 기준 전체 분당 60회, 위치 인증과 글 등록 각각 분당 5회이며 다중 서버 운영에서는 공유 저장소가 필요하다.

이는 기기가 보고한 위치와 지역의 일치 검사다. GPS 조작·변조된 클라이언트를 완전히 막거나 실거주를 증명하는 기능은 아니다. 운영 확장 전 기기 증명, 신고·검토 흐름은 별도 보강 대상이다. 실제 글이 없으면 빈 목록을 보여주며 가짜 인증 글을 넣지 않는다.

`RegionClient`는 외부 통신과 DTO 검증, `CommunityService`는 인증·권한·만료 정책, `CommunityRepository`는 DB 접근을 담당한다. 좌표를 저장하는 컬럼은 없다. `npm run prisma:deploy`로 마이그레이션을 적용하고 API를 재시작한다. `tests/unit/community.test.mjs`에서 지역 불일치·만료·미래 위치·탈퇴 계정·관리자 권한·좌표 미저장을 검증한다.

공식 참조: [Google reverse geocoding](https://developers.google.com/maps/documentation/geocoding/requests-reverse-geocoding), [Geocoding 정책](https://developers.google.com/maps/documentation/geocoding/policies).

## 웹·앱 화면

장소 추가의 ‘장소 추천 / 방문자 추천’ 탭으로 전환한다. 방문자 탭은 인증할 지역의 표시 이름을 먼저 보여준다. 위치 전송 동의 후 버튼을 눌렀을 때만 위치를 가져오며, iOS는 foreground 권한만 요청하고 웹은 브라우저 위치 API를 사용한다. 권한 거부·시간 초과·정확도 부족·지역 불일치 오류를 보여준다. 인증 만료 시 작성 폼을 닫고 재인증을 안내한다.

작성 폼에는 장소명, 선택 주소, 10자 이상 추천 이유를 입력한다. 게시글에서 장소 검색으로 이동해 공급자의 실제 장소를 선택한 뒤 여행에 담는다. 게시글의 사용자 입력을 Google 장소 정보로 자동 복사하지 않는다. 삭제는 확인 창을 거친다. 페이지 이동·빈 상태·다시 불러오기를 제공한다. 샘플 모드에서는 실제 글이나 인증을 가장하지 않는다.
